## Problem Statement

Implement a singly linked list in C++ to maintain bank account records. Each node stores the account number, account holder name, and balance. Perform insertion, deletion, searching, and display operations.

### Approach

The Bank Account Management System is implemented using a singly linked list in C++. Each node stores the account number, account holder name, balance, and a pointer to the next node. The system performs insertion to add new account records, deletion to remove an account, searching to find an account using its account number, and display to show all account records. Dynamic memory allocation is used to create nodes as required, making the system flexible and suitable for managing bank account records.

## Complexity Analysis


Operation	   :-	          Time Complexity (Worst Case)	  :-	       Space Complexity	

Insertion (at Head):-	O(1)   :-	  O(1)

Insertion (at Tail):-		O(N) :-	 O(1)

Deletion	:-	O(N) :-	 O(1)	

Searching:-		O(N) :-	 O(1)

Display:-		O(N) :-	O(1)

### Conclusion

The Bank Account Management System using a singly linked list was successfully implemented in C++. It allows users to insert, delete, search, and display bank account records efficiently. Each node stores the account number, account holder name, and balance. This project demonstrates the practical use of linked lists and dynamic memory allocation for managing records. It improves understanding of basic data structures and their applications in real-life banking systems.
