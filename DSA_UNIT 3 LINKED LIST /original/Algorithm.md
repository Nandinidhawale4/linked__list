## Algorithm

1 Start and initialize head = NULL.

2 Create a node containing account number, name, and balance.

3 For insertion, connect the new node at the beginning of the list.

4 For deletion, search for the required account number and adjust the links.

5 For searching, traverse the list and compare the account number.

6 For display, traverse from head to NULL and print all records.

7 Repeat the operations according to the user's choice.

8 Stop.
