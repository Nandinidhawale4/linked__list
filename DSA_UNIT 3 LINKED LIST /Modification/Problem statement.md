## problem statement

To implement a Bank Account Manage-ment system using stack and Queue with dynamic memory allocation in C++. The system stores bank account details such as account number, account holder name, and balance. A stack is used to manage account operation in Last In First out (LIFO) order, while a Queue is used to manage account operation in First In First out (FIFO) order. The system perform insertion, deletion, display, and account searching operation using dynamically allocated nodes.
