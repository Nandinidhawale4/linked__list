## Title

Tree Terminology Identification and Analysis using c++

## problem statements 
Write a C++ program to construct a tree and identify its root node, leaf nodes, internal nodes, and degree of each node. Display the parent and children of each node, calculate the depth of each node, and determine the height of the tree.

## objective

 To Construct a tree using c++
 
 To Identify the root, leaf, and internal nodes.
 
 To Calculate the degree of each node.
 
 To Display the parent and children of each node.
 
 To Calculate the depth of each node.
 
 To Determine the height of the tree.
 
## Algorithm 

1 Start the program
   
2 Create a binary tree using linked node

3 Assign values to the nodes and construct the tree
 
4 Identify and display the root node
 
5 Display the parent and children of each node
 
6 Calculate and display the degree of each node
  
7  Identify and display the leaf and internal nodes
    
8 Calculate and display the depth of each node.
  
9 Calculate and display the height of the tree.
  
10 Stop the program.
