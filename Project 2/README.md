## Title
Tree Terminology Identification Using C++

## Problem Statement

Write a C++ program to construct a tree and identify its root node, leaf nodes, internal nodes, degree of each node, and height of the tree.

## Objectives

To understand the basic terminology of trees in data structures.
To construct a tree using C++.
To identify the root node, leaf nodes, and internal nodes.
To calculate the degree of each node.
To calculate the height of the tree.
To understand the implementation of trees using linked structures.

## Algorithm

1 Start the program.

2 Create a tree node structure containing data and pointers to child nodes.

3 Construct the tree by inserting nodes.

4 Display the root node of the tree.

5 Identify and display all leaf nodes.

6 Identify and display all internal nodes.

7 Calculate and display the degree of each node.

8 Calculate and display the height of the tree.

9 Stop the program.

## TIME Operation

Let n be the total number of nodes in the tree.

Operation                            Time Complexity   
Tree Construction                      O(n)
Finding Root Node                      O(1)
Identifying Leaf Nodes                 O(n)
Identifying Internal Nodes             O(n)
Calculating Degree of Each Node        O(n)
Calculating Height of Tree             O(n)
Displaying Tree Terminology            O(n)

Overall Time Complexity: O(n)
Space Complexity: O(n)

## conclusion

Thus, the C++ program successfully constructs a tree and identifies the root node, leaf nodes, internal nodes, degree of each node, and height of the tree. This program helps to understand basic tree terminology and the concept of tree traversal in data structures.
